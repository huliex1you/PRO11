مركز التقارير المتقدمة للموارد البشرية

تقارير القوى العاملة (Headcount)

  • العدد الإجمالي حسب الإدارات والفروع
  • التركيبة الديموغرافية (جنسيات، أعمار)
  • نسب التوطين ونطاقات

تقارير التوظيف والاستقطاب

  • المرشحين ومصادر الاستقطاب
  • تكلفة ومدة التوظيف (Time to Hire)
  • معدلات قبول العروض الوظيفية

تقارير الحضور والغياب

  • ساعات العمل والإضافي (Overtime)
  • معدلات التأخر والغياب
  • التوازن بين الحضور الفعلي والمخطط

تقارير الإجازات

  • أرصدة الإجازات السنوية والمرضية
  • الإجازات المجدولة والمستحقة
  • تكاليف الاستبدال أو التعويض

تقارير الرواتب والأجور

  • مسير الرواتب الشهري (Payroll)
  • حماية الأجور (WPS / مدد)
  • مقارنات الرواتب مع السوق

التأمينات ونهاية الخدمة

  • اشتراكات التأمينات (GOSI)
  • مستحقات ومخصصات نهاية الخدمة
  • تقارير الرعاية الطبية

تقارير الأداء

  • نتائج التقييم السنوي/نصف السنوي
  • توزيع التقييمات الشاملة
  • مؤشرات الأداء الرئيسية (KPIs)

التدريب والتطوير

  • المتدربين وساعات التدريب
  • تكلفة التدريب لكل موظف
  • قياس أثر التدريب ورضا المتدربين

الدوران الوظيفي (Turnover)

  • معدل الدوران الطوعي وغير الطوعي
  • معدل الاحتفاظ بالمواهب (Retention)
  • تحليل أسباب الخروج والاستقالات

الامتثال والالتزام

  • الامتثال لوزارة الموارد البشرية
  • سجلات عقود العمل والتحقق
  • منصات قوى ومدد

رضا الموظفين والمشاركة

  • استطلاعات الرضا (Engagement)
  • مؤشر ترويج الموظفين (eNPS)
  • تحليل بيئة العمل

التقارير الاستراتيجية

  • لوحات المؤشرات للإدارة (Dashboards)
  • الموازنة والتخطيط للقوى العاملة
  • مقارنة الأهداف بالنتائج
